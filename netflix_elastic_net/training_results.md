# Elastic Net 电影时长预测：训练结果

数据来源：https://www.kaggle.com/datasets/paramvir705/netflix-dataset

## 实验方法

清洗后共 6,131 部电影。输入为上映年份、制作国家、影视类型和年龄分级，目标为分钟时长。国家和类型按多标签编码，分级按类别编码。固定随机种子 42，80% 训练、20% 测试，共 4,904 条训练记录和 1,227 条测试记录。

编码、标准化、Elastic Net 置于同一个 Pipeline 中；在训练集上使用打乱的五折交叉验证。搜索 alpha=[0.01,0.1,0.5,1,5]、l1_ratio=[0.1,0.5,0.9]，以均方误差选择参数。测试集不参与参数选择。scikit-learn 的 alpha 表示正则化强度，l1_ratio 表示 L1 比例，与课上常用数学符号的名称不同。

## 实际结果

最优 alpha=0.1，l1_ratio=0.9。交叉验证 RMSE 为 20.48 分钟。

| 模型 | 测试 MAE（分钟） | 测试 RMSE（分钟） | 测试 R² |
|---|---:|---:|---:|
| Elastic Net | 14.41 | 20.10 | 0.4554 |
| 训练集平均时长基线 | 19.52 | 27.25 | -0.0008 |

相较基线，测试 MAE 降低约 26.2%，RMSE 降低约 26.2%。R²=0.4554 表示在此测试集上，相对于用测试集均值定义的总平方偏差，模型减少约 45.5% 的平方误差，不是“预测准确率 45.5%”。

编码后有 144 个特征，其中 114 个系数非零。以标准化系数绝对值排序，印度制作、剧情、TV-Y 分级、脱口秀等特征关联较强。印度制作、剧情的系数为正，TV-Y、脱口秀、纪录片的系数为负。它们是控制其他输入后的模型关联，不表示因果关系；相关类别、稀有类别及编码方式都会影响系数，不能把绝对值排序视为唯一可靠的重要性结论。

## 局限

诊断图显示预测趋向中间时长，特别短的影片常被高估，特别长的影片常被低估。模型只使用有限目录特征，不能解释全部时长差异。随机划分衡量同类数据中的预测效果，不代表未来上映电影的效果。本实验不是用户评分预测，也不是个性化推荐。

```bash
python -m pip install pandas numpy scikit-learn matplotlib

```

运行环境：Python，scikit-learn 1.8.0。02_train_model.py 带中文注释。model_metrics.json 为指标和参数，cross_validation.csv 为候选参数比较，coefficients.csv 为全部系数，test_predictions.csv 为测试预测和残差，model_diagnostics.png 为预测散点图和残差图。

系数表中的 standardized_coefficient 是缩放后的特征系数；coefficient_original_units 是除以训练集特征标准差后换算的原单位系数。二元特征原单位系数对应从 0 到 1 的模型预测变化，年份对应增加一年的变化。
